WHAT IS BTMS?

One platform for the college transport ecosystem.

BTMS brings together student access, bus information, route plans, GPS-based location updates and administrative management into a single system.

Live Bus Location

Students can view available bus locations and their current movement status through the application.

Route & Plan Management

Transport routes can be organized into plans such as Plan A, Plan B, Plan C and other active route plans.

Controlled Access

Student accounts are created through college data, while organization features are available only to authorized administrators.

SYSTEM JOURNEY

From college data to a student's screen.

BTMS connects administrative information and GPS data before presenting the required transport information to students.

01

College Data

Student and route information can be uploaded through Excel-based organization tools.

02

BTMS Backend

The backend manages authentication, bus data, routes, users and live location information.

03

GPS Information

GPS information associated with buses is processed by the system for location updates.

04

Student Application

Students can view their assigned bus and explore other available buses and route information.

CORE CAPABILITIES

What can users do with BTMS?

Track Buses

View available bus locations and movement status from the home interface.

Search Buses

Search for another bus when transport information outside the assigned bus is required.

Refresh Location

Refresh the available bus information from the application interface.

View Stoppings

View the stopping points associated with a bus route along with route information.

Global Plans

View the currently active transport plan and see buses associated with that plan.

Profile

Students can access their profile information through their account.

ACCESS MODEL

Different users. Different responsibilities.

BTMS separates student functionality from administrative organization capabilities.

STUDENT

Transport User

  • Login with college account credentials
  • View assigned bus
  • Search other buses
  • View route stoppings
  • View movement status
  • View global transport plan
  • View profile
SUPER ADMIN

Transport Organization

  • Create student accounts through Excel
  • Manage uploaded student data
  • Create and configure buses
  • Configure GPS information
  • Manage bus numbers
  • Manage route plans
  • Access organization tools
