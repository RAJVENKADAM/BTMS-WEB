START WITH THE STUDENT

A student opens BTMS. What happens next?

The following workflow explains the complete system in the same order in which the information moves through BTMS.

01
STUDENT DATA

The Super Admin creates student accounts.

Student information is managed by the college Super Admin through the Organize → Create Users section.

The Super Admin can upload student details using Excel sheets. Multiple sheets can be uploaded as required by the organization.

Excel Upload

Student details are imported into the system through Excel-based organization.

Student Records

Uploaded student information becomes available for controlled login access.

Multiple Uploads

More than one student sheet can be uploaded when required.

02
AUTHENTICATION

Only registered students can log in.

A student can access BTMS only when the student's information exists in the uploaded college data.

The login password follows the configured college-data format:

Password format First 4 digits of mobile number + Birth Year 9629 + 2006 = 96292006

If the corresponding student data is removed from the system by the administrator, that student will no longer be able to authenticate through that organization record.

03
BUS CONFIGURATION

The Super Admin creates and configures buses.

Bus information is managed from Organize → Create Bus.

The administrator provides the bus information required by the system, including GPS identification, bus number and previous number information.

GPS Number Identifies the GPS information associated with the bus.
Bus Number The bus identifier used within BTMS.
Previous Number Previous bus numbering information can be maintained.

04
ROUTE MANAGEMENT

Routes are organized through transport plans.

Route information can be provided through route Excel sheets and organized into plans such as Plan A, Plan B, Plan C and other configured plans.

Each bus can therefore be associated with the route information required for that transport plan.

05
HOME DASHBOARD

The student reaches the bus information directly.

After authentication, the home screen can use the student's assigned bus information so that the student does not need to search for their own bus every time.

Assigned Bus Access the bus associated with the student's account.
Search Search and explore another available bus.
Refresh Refresh the available bus location information.

06
LIVE BUS INFORMATION

The student can see where the bus is.

BTMS receives GPS information associated with configured buses and makes the available location information accessible through the application.

The map interface presents the bus location together with relevant route information.

Moving Bus movement detected by the system.
Waiting Bus remains at a location.
Stopped Bus location remains unchanged.
07
BUS SEARCH

Students can also search for another bus.

The assigned bus is available directly from the student's home experience, but BTMS also allows the student to search for other available buses.

Search bus...
Bus Information Route and current status

Searching a bus opens its available transport information rather than requiring the student to know its route beforehand.

08
BUS DETAILS

Each selected bus provides useful transport information.

After selecting a bus, the student can view the information available for that bus and its route.

Stoppings View the stopping points associated with the selected route.
Distance View the available distance information associated with the bus location.
Movement Status Understand whether the bus is moving, waiting or stopped.
09
GLOBAL PLAN

The active transport plan is visible to everyone.

The application provides a global plan button that shows which transport plan is currently active.

Selecting the plan allows users to see the buses associated with that plan.

10
PROFILE

Personal information remains accessible from the profile.

Students can open the profile section from the application to view their account information.

The profile experience provides a clear separation between personal account information and transport tracking features.

11
ADMINISTRATION

The Super Admin gets the organization layer.

The Organize button is available only to the Super Admin.

This keeps administrative functions separate from the normal student experience.

Create Users Upload student information through Excel.
Create Bus Configure bus and GPS information.
Route Data Organize route plans and stopping information.
Excel Import Bring structured transport information into the system.
